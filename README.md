# desk

A private investment decision journal with an opinionated scoring engine. Spec: [`docs/BRIEF.md`](docs/BRIEF.md).
It does not trade and it is not investment advice.

## Status

| Phase | Scope | State |
|---|---|---|
| 1 | Skeleton, all fetchers with recorded fixtures, daily scheduler, tape dashboard | **done** |
| 2 | Safra PDF extraction, seed house views, Revolut screenshot ingestion, portfolio view | not started |
| 3 | Regime, conviction score, rules engine, decisions | not started |
| 4 | Self-scoring, weekly digest, Claude-written reasoning | not started |

## Run locally

```bash
uv sync
cp .env.example .env            # fill in keys; basic auth user/pass are required
uv run desk init-db
uv run desk load-fixtures       # offline demo data, tagged source='fixture:*'
uv run desk fetch               # live data (needs network + keys)
uv run desk serve               # http://localhost:8000
uv run pytest                   # network is disabled for every test
```

`DESK_ALLOW_NO_AUTH=1 uv run desk serve` skips basic auth for local development only.

## Deploy (Hetzner, Docker Compose)

```bash
cp .env.example .env && $EDITOR .env
docker compose up -d --build
```

One `app` container runs FastAPI and the APScheduler daily job (07:00 Europe/Berlin) in a single process.
SQLite, inbox, archive and nightly backups live in the `desk_data` volume under `/data`.
Put Caddy in front for TLS (`Caddyfile.example`). Backups: `sqlite3 .backup` nightly at 02:00, newest 30 kept in
`/data/backups`; rsync to the IMPROVR backup target is a host cron job, not part of the container.

## Data sources

| Source | Series | Key |
|---|---|---|
| yfinance | daily OHLCV for everything in `config/universe.yaml` | none |
| FRED | DFF, DGS2, DGS10, DGS30, CPIAUCSL, CPILFESL, T10Y2Y, UNRATE | `FRED_API_KEY` |
| ECB Data Portal | ECB_DFR, EZ_HICP, EZ_HICP_CORE | none |
| Alpha Vantage NEWS_SENTIMENT | per-ticker and per-topic daily sentiment; 25 calls/day budgeted in `data/cache` | `ALPHAVANTAGE_API_KEY` |
| GDELT DOC 2.0 | tone + volume for six fixed queries | none |
| CNN Fear & Greed | CNN_FEAR_GREED (optional, unofficial) | none |
| manual | `config/manual_observations.yaml` (Egypt); red on the dashboard after 14 days | none |

Every fetcher is `_raw()` (network) + `parse()` (pure). `run()` retries three times and then replays the
last good payload from `data/cache/<source>.last_good.json`, so a dead API never blanks the dashboard.
Each run writes a `fetch_runs` row shown in the Sources table.

## Fixtures

`tests/fixtures/*.json` are the raw payload shape of each API. **The shipped files are synthetic placeholders**
generated by `scripts/make_synthetic_fixtures.py` (this build environment has no access to the data hosts).
Record real payloads with:

```bash
uv run python scripts/record_fixtures.py
```
