# Repository contents

- **`laseq/`** — Laseq (لاصق), a car-advertising marketplace for Egypt (brands pay drivers
  per km to carry ads on their cars). See [`laseq/README.md`](laseq/README.md) for setup,
  demo accounts and architecture.
- Root `*.java` files — an earlier Love Letter card-game / chat-server project, unrelated to Laseq.
